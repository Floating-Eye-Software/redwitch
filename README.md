# Red Witch

Privacy-first cycle tracking and reproductive health software.

Red Witch is a FLEY project focused on:

- cycle tracking
- symptom tracking
- reproductive health journaling
- fertility-awareness support
- privacy-preserving personal health records
- user-controlled interpretation overlays

## Philosophy

Red Witch is built around:

- privacy first
- local-first principles
- data sovereignty
- explicit consent
- exportability
- separation of data and interpretation
